# 默认创作入口使用说明

「开始一集」是 PodFlow Studio 的默认桌面入口。它不会建立另一套工作流，而是使用
当前 `EpisodeRun schema v3` 和 `morning_news_brief` preset，把现有节点自动编排到
可审阅稿件，确认后再制作声音。

## 发起生成

输入区支持主题或指定素材，并可补充听众和希望听众带走的收获：

- 关注主题：把主题传给发现节点，用于相关度筛选；
- 指定素材：每行一个公开 HTTP/HTTPS 链接，或直接粘贴正文文字。

手动网页读取只接受公开地址，拒绝本机和内网地址，并限制重定向次数、响应体大小、
内容类型和读取超时。单个链接失败不会伪造正文；失败原因保存在
`discover_meta.manual_input_errors`，其他有效来源仍可继续处理。人工笔记会保留
`manual` 来源类型，不能冒充独立新闻来源。

## 自动阶段

首页自动完成前三个阶段；声音制作由审稿后的明确操作发起：

```text
收集素材    fetch + preprocess
核验与选题  research + topic_selection + facts
撰写节目    script
生成声音    tts + audio_postprocess + review
```

运行前检查 AI 成稿配置，不要求声音配置；声音服务在制作阶段检查，mock 音频不能正式发布。
缺少成稿配置时引导进入智能能力设置。任务由 Electron 后台执行，切换页面不会取消当前节点。重新打开
应用后，可以从节目库查看最后一次持久化的阶段和失败原因，并从对应阶段重跑。

## 试听与发布边界

默认入口在 Script 后保存并停止，不自动配音或 Publish。打磨内容页提供编辑和来源核对；
确认后进入试听交付，制作音频、机器审核、人工终审和导出仍沿用现有门禁。结果页可能显示：

- 草稿试听：已有音频，但机器门禁仍有失败或待处理项；
- 预览已就绪：机器门禁通过，等待绑定当前音频指纹的人工终审；
- 可以正式发布：机器门禁和人工终审均已通过。

只有 `release_readiness.status == publish_ready` 的当前音频才允许正式发布。快速入口不会
跳过来源核验、事实检查、稿件门禁、发音预检、音频质量检查或人工终审，也不会把
mock 音频包装为正式节目。

## 公开样例

首页的「先试听公开样例」会打开项目产品页中的真实节目播放器。样例不是本地 demo
生成的 mock WAV；离线 demo 仍只用于验证技术链路，并持续保留 `demo_only` 标记。
