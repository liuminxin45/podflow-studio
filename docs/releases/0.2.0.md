# PodFlow Studio 0.2.0

PodFlow Studio 0.2.0 将桌面端从可运行的播客流水线升级为统一、可验收的本地 AI 新闻播客工作台。本版本重点完成全局 UI/UX 重构、AI 驱动的深度稿发现、Agent 可调用 CLI，以及无需系统安装的 FFmpeg 音频运行时。

## 主要更新

### 统一的企业级工作台

- 全量重构节目库、发现、整理、写作、制作、发布和设置页面，统一为简约、轻量、无彩色干扰的视觉体系。
- 合并重复导航与重复的新建入口，统一页面层级、列表密度、下拉菜单、确认弹窗和状态反馈。
- 修复素材发现中栏溢出、列表分隔、流程完成状态和跨页面创建请求重复消费等问题。
- 工作流失败会持续显示真实原因，不再被瞬时提示掩盖。

### AI 驱动的深度稿发现

- 调整深度稿顺序：先由 AI 分析与网络研究识别高潜力事件，再标记为深度稿并继续扩展证据。
- 新增批量筛选、证据质量控制、深度稿选择流程和对应测试。
- 加入豆包联网搜索来源，并强化事实卡片、编辑计划和稿件质量边界。

### 面向 AI Agent 的 CLI

- 新增 `podflow doctor`、`start`、`run`、`status`、`stop` 和 `accept` 命令。
- 支持隔离会话、隐藏窗口、固定 CDP 端点、运行清单、日志、截图与机器可读验收结果。
- `npm run acceptance:cdp` 可在无人值守环境验证发现、写稿、录音、发布和设置主路径。

### 音频生产与可移植运行时

- `npm install` 会自动安装当前平台的 FFmpeg，Electron 与 Python 节点共享同一运行时，无需单独配置系统 FFmpeg。
- FFmpeg 会随 Windows 应用解包分发，并保留其 GPL-3.0-or-later 许可证文件。
- 完善表达性语音方向、分段制作计划、录音状态管理和音频后处理流程。

## 安装与升级

1. Windows 用户可从本 Release 的 Assets 下载 `.exe` 安装程序。
2. 源码运行需要 Node.js 22、Python 3.13，以及正常执行安装脚本的 `npm install`。
3. 首次源码运行执行 `npm run setup:python`，再使用 `npm run dev` 或 `npm run cli -- doctor` 检查环境。

当前 Windows 安装包未进行商业代码签名，Windows SmartScreen 可能显示发布者提示。
